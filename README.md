# gigadiet

iOSアプリ「ギガダイエット」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開します。

- サポート: https://taaaaho.github.io/gigadiet/
- プライバシーポリシー: https://taaaaho.github.io/gigadiet/privacy.html
- 利用規約: https://taaaaho.github.io/gigadiet/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

ソースコードは非公開リポジトリで管理しています。
